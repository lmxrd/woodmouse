# woodmouse

Client-rendered React SPA built with Vite, Tailwind CSS, TanStack Router
(file-based), and TanStack Query. Managed with pnpm.

## Commands

| Command      | What it does                                   |
| ------------ | ---------------------------------------------- |
| `pnpm dev`   | Dev server at http://localhost:5173            |
| `pnpm build` | Typecheck + production build                   |
| `pnpm test`  | Run vitest tests                               |
| `pnpm check` | Typecheck + oxlint + oxfmt --check (read-only) |
| `pnpm fix`   | oxlint --fix + oxfmt (auto-fix)                |

## Layout

- `src/routes/` — file-based routes (one file per route, `__root.tsx` for the shell)
- `src/components/` — shared components
- `src/lib/` — shared utilities (e.g. `queryClient`)
- `src/routeTree.gen.ts` — generated by the vite plugin; committed, do not edit
